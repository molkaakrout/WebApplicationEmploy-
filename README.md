# TP N°1 : Gestion des Employés (ASP.NET Core MVC)

Application web de gestion des employés avec le pattern Repository et LINQ (données en mémoire).

## Technologies
- ASP.NET Core MVC
- C# / LINQ
- Bootstrap (thème Bootswatch Morph)

## Lancer le projet
1. Ouvrir la solution dans Visual Studio 2022
2. Appuyer sur F5
3. Cliquer sur **Liste Employés** dans la barre de navigation

## Fonctionnalités
- CRUD Employés
- Recherche par nom
- Validation de la saisie (Required, StringLength, Range)
- Statistiques : nombre d'employés, salaire moyen, salaire max, employés du département HR
